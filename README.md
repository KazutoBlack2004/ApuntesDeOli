# ApuntesDeOli

Sitio de apuntes organizado por áreas de estudio, construido con Astro y React.

## Sitio publicado

Puedes abrir la página aquí:

[https://kazutoblack2004.github.io/ApuntesDeOli/](https://kazutoblack2004.github.io/ApuntesDeOli/)

## Comandos

| Comando | Acción |
| :-- | :-- |
| `npm install` | Instala las dependencias |
| `npm run dev` | Inicia el servidor local |
| `npm run build` | Genera la versión de producción |
| `npm run preview` | Previsualiza el build local |
